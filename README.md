🧥 Chaves Store

Site desenvolvido como exercício prático do curso de webdesign, simulando uma loja virtual de jaquetas.

📖 Sobre o projeto

O Chaves Store é uma landing page de e-commerce fictícia, criada para colocar em prática os conceitos de HTML, CSS e JavaScript aprendidos durante o curso. A loja apresenta um catálogo com 6 modelos de jaquetas, permitindo ao usuário simular a experiência de compra: adicionar produtos ao carrinho e acompanhar o valor total da compra em tempo real.

✨ Funcionalidades
🛍️ Catálogo com 6 jaquetas, cada uma com foto e informações do produto
🎨 Botões interativos: ao passar o mouse, a seta muda e a cor do botão se altera
🛒 Adicionar produtos ao carrinho com JavaScript
💰 Cálculo automático do valor total para finalizar a compra
🖼️ Logo personalizado da loja
🔤 Ícones para deixar a interface mais bonita e intuitiva
🛠️ Tecnologias utilizadas
HTML5 — estrutura da página
CSS3 — estilização, cores e efeitos visuais nos botões
JavaScript — lógica do carrinho de compras e soma do total
Ícones — para elementos visuais da interface
